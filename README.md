# Análisis cognitivo de la atención visual del consumidor: experimento mediante seguimiento ocular y análisis estadístico con Python

Este repositorio contiene la metodología cuantitativa, el script de procesamiento de datos y las visualizaciones correspondientes al estudio estadístico y cognitivo sobre la jerarquía visual de los envases cosméticos a partir de datos de seguimiento ocular (*eye-tracking*).

## Resumen del Proyecto
El estudio evalúa la distribución de la atención visual en las caras frontal y posterior del envase de una mascarilla capilar (20 participantes, rango de edad 20-30 años). Se analizaron áreas de interés (AOI) mediante métricas oculomotoras como el tiempo hasta la primera fijación (TFF), la duración total de las fijaciones, el número de revisitas y la proporción de observadoras. El procedimiento se implementó en Python 3.13.

## Estructura del Repositorio
